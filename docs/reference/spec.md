A numbered index of every normative requirement felis holds itself to, REQ-001 through REQ-1206. Each row states the
requirement once and links the page that commits to it, where the wire details, the ranges, and the argument live.

Requirement levels follow RFC 2119: **MUST** is non-negotiable and a failure is a defect, **SHOULD** is strongly
preferred and a deviation needs a documented justification, **MAY** is optional. **NOT** marks a capability that is out
of scope; [non-goals.md](../explanation/non-goals.md) is the authority for those.
